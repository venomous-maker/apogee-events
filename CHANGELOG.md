# Changelog

Every release of apogee-events, newest first. Each is a `vX.Y.Z` tag with a GitHub
release carrying its section; the `grav` line in `grav.toml` says which
compiler versions it builds with.

## Unreleased

## 0.1.0 (2026-11-19)

The first tagged release. Needs grav 1.7.0 or newer.

Events for [Apogee](https://github.com/venomous-maker): something happened; whoever cares is told. Typed listeners, listener classes built by the container, subscribers, discovery, named events with wildcards, priorities, stoppable events, dispatch held until a transaction commits, queued listeners, async dispatch, and a fake for tests.
